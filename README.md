# 🏥 Hospital Management System

A web-based **Hospital Management System** developed using **ASP.NET MVC, C#, ADO.NET, SQL Server, HTML, CSS, JavaScript and Bootstrap**.

The project is designed to manage hospital-related information efficiently using **CRUD (Create, Read, Update, Delete) operations**.

## 🚀 Features

* 👨‍⚕️ Doctor Management
* 👨‍👩‍👧 Patient Management
* 📅 Appointment Management
* ➕ Add Records
* 📋 View Records
* ✏️ Update Records
* 🗑️ Delete Records
* 🔍 Search & Manage Data
* 🗄️ SQL Server Database Integration
* 📱 Responsive User Interface

## 🛠️ Technologies Used

* **C#**
* **ASP.NET MVC**
* **ADO.NET**
* **SQL Server**
* **HTML5**
* **CSS3**
* **JavaScript**
* **Bootstrap**
* **Visual Studio**

## 🔄 CRUD Operations

| Operation  | Description                                    |
| ---------- | ---------------------------------------------- |
| **Create** | Add new doctor, patient or appointment records |
| **Read**   | Display stored hospital records                |
| **Update** | Edit existing records                          |
| **Delete** | Remove unwanted records                        |

## 🗄️ Database

The application uses **Microsoft SQL Server** for storing and managing hospital data.

**ADO.NET** is used for database connectivity and performing CRUD operations.

## 🎯 Project Objective

The main objective of this project is to provide a simple and organized system for managing hospital information while demonstrating practical implementation of **ASP.NET MVC, C#, ADO.NET and SQL Server CRUD operations**.

## ⚙️ How to Run

1. Clone the repository.
2. Open the `.sln` file in **Visual Studio**.
3. Configure the SQL Server connection string.
4. Create/import the required database and tables.
5. Build the project.
6. Run the application using **IIS Express** or Visual Studio.
